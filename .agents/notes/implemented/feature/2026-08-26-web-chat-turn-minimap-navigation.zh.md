# Agent Note: Web 对话轮次缩略图导航

Status: implemented

[English](2026-08-26-web-chat-turn-minimap-navigation.md) | 中文

## Problem

Web 客户端中较长的对话记录使用户难以直观追踪对话进展、理解轮次层级，并且无法在不进行大量手动滚动的情况下快速跳转到特定的用户提问和助手回复。

## Decision

在对话滚动区域左侧添加垂直轮次缩略导航组件（`TurnTimelineNav`）。

对话时间线中的每个轮次都会投影为一个细微的水平短线指示器（`-`）。悬停在任意短线上会显示一个紧凑的悬浮预览卡片，展示用户提问和助手回复摘要。点击短线会通过计算顶部偏移平滑滚动聊天直接定位到该轮次。视口中当前活动的轮次会通过带节流的滚动监听自动高亮显示。容器布局保持 `min-height: 100%`，确保缩略导航从第一条消息开始就稳定锚定在屏幕垂直中心。

## Alternatives considered

**在侧边栏内嵌入缩略图。** 侧边栏用于管理工作区会话，而非会话内部轮次导航；混合会话管理和会话内导航会使侧边栏过于杂乱。

**浮动大纲弹窗。** 弹窗需要显式的打开/关闭操作且会遮挡对话内容，而左侧对齐的细微标尺提供了持久的环境定位且不造成干扰。

## Consequences

用户可以快速浏览、预览并跨多个对话轮次导航，获得持久的视觉方向感且不产生任何布局抖动。
