# Agent 笔记：会话头部与伴随侧边栏 UI 现代化改造

状态：implemented

[English](2026-08-24-header-sidepanel-modernization.md) | 中文

## 背景

此前的会话头部在主要滚动列中包含独立的 Chat／Trajectory 切换标签条，伴随侧边栏则采用固定的三标签页结构。实际使用中需要更快捷的工作区上下文（项目／目录标识）、快速会话任务操作（重命名、路径与会话 ID 复制、文件资源管理器打开、会话日志导出下载）、直接的交互式终端访问，以及容纳轨迹检查、代码评审、网页浏览和任务列表的灵活多标签伴随工作区。

## 决策

1. **会话头部界面**：
   - 移除原头部下方的 Chat／Trajectory 切换标签条，统一整合为单行标题栏，包含层级面包屑、项目目录徽标（显示所属工作区标题或 `Default`）、包含快捷操作（重命名、在文件管理器中打开、复制路径与会话 ID、查看模型轨迹、导出日志等）的省略号（`···`）菜单、智能体模式徽标、终端启动按钮与侧边栏切换按钮。
2. **伴随侧边栏多标签体系**：
   - 在 `DetailsPanel` 中引入多标签页体系，支持标签页胶囊、关闭按钮（`×`）、面板折叠（`⌄`）以及添加标签操作（`+`）。
   - 增加无活动标签时的“打开标签”选择视图，便于选择打开 Side conversation、Trajectory、Review、Terminal 或 Browser。
   - 增加具备 PowerShell 风格与会话 `cwd` 提示符的交互式终端视图。

## 影响

- 头部栏提供紧凑、信息密集的单行布局，可即时访问项目上下文与会话操作。
- 伴侣侧边栏支持多标签工作流，使开发者无需离开主对话即可在轨迹日志、代码评审与实时终端之间自由切换。

## 备选方案

- **保留二级标签栏** — 已否决，因为其占用纵向屏幕空间且无法提供灵活的并排检查工作流。
- **固定三标签布局** — 已否决，因为其限制了开发者同时打开多个辅助工具（如在代码评审旁并行开启终端）。
