# @const-ai/client-ui-design

English | [中文](README.zh.md)

OpenDesign Studio UI for Const Harness: visual landing home, prompt template carousel, brand design system picker popover, craft guidelines, and template preview drawer.

## Model Experience

None, as the UI renders design catalogs, systems, and prompt templates in the browser; session prompt execution delegates to standard agent loop sessions.

#### KV Cache effect

None; this package neither assembles nor sends a provider request.

## Known Limitations and Deferred Work

- **Figma file import is a UI modal placeholder** — live canvas token ingestion from Figma REST API is deferred to a dedicated Figma integration provider.
