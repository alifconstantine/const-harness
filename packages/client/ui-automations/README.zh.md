# @const-ai/client-ui-automations

[English](README.md) | 中文

定时任务与自动化管理前端包：提供自动化任务仪表盘、创建表单、执行历史记录以及定时配置视图。与宿主端自动化 API 进行交互，管理周期性后台任务并查看执行日志。

组件支持以多种周期频率（每小时、每天、工作日、每周、每月及自定义时间间隔）创建计划任务，配置权限预设，并将执行绑定到指定的工作区目录。

## Model Experience

无，此包为纯浏览器端 UI 界面，未注册任何面向模型的内容。

#### KV Cache effect

无；本包既不组装也不发送任何提供商请求。

## Known Limitations and Deferred Work

- **依赖宿主端调度** — 自动化任务执行由宿主进程驱动；若宿主停止，未执行的调度将在下次启动时补齐评估。
- **单任务单实例执行** — 同一自动化任务不可并发重叠运行，后续触发需等待前次会话结束。
